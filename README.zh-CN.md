# Mesh管理

[English](README.md) | **简体中文**

基于 OpenWrt 原生无线组件、usteer 和 802.11k/v/r 的 Mesh 管理工具。
通过简洁的 LuCI 界面完成组网、Wi-Fi 配置和 AP 节点集中管理。

一个 Mesh 网络由一台管理主节点和多台 AP 组成。AP 可通过有线连接加入，
也可使用主节点的 Wi-Fi 名称和密码无线加入。

## 功能

- 统一管理 Wi-Fi 名称、密码和 802.11k/v/r 漫游配置。
- 使用 OpenWrt 官方 usteer 提供终端漫游引导。
- 支持有线回程、802.11s 无线回程，以及有线优先、无线备用。
- 自动发现主节点、加入网络并同步配置。
- 查看网络拓扑、节点状态、回程质量、终端和变更记录。
- 应用前预览配置，配置未通过健康确认时自动回滚。
- 自动分配 Guest VLAN 和独立子网，支持访客密码、上网和 LAN 访问策略。
- 按节点硬件与当地法规规划客户端频段、信道、带宽和功率上限。
- 关闭 Mesh 时恢复接管前的托管配置，支持退出后重新加入。

## 安装

### 环境要求

- 使用与目标设备匹配的 OpenWrt 构建环境；设备固件需包含完整 LuCI。
- 主节点和 AP 均安装 `mesh-manager` 与 `luci-app-mesh-manager`。
- 使用无线回程时，无线芯片和驱动需支持 802.11s、SAE，
  以及 AP 与 Mesh 接口同时运行。

### 添加软件源并编译

在 OpenWrt 构建目录实际使用的 feed 配置文件中添加以下内容：
使用 `feeds.conf`；若该文件不存在，则使用 `feeds.conf.default`。

```text
src-git mesh_manager https://github.com/JiaY-shi/mesh-manager.git
```

在构建目录执行：

```sh
./scripts/feeds update -a
./scripts/feeds install -p mesh_manager mesh-manager luci-app-mesh-manager
./scripts/feeds install -a
make menuconfig
```

选择目标设备，并按需选择以下软件包：

| 软件包 | 用途 |
| --- | --- |
| `mesh-manager` | Mesh 管理后台 |
| `luci-app-mesh-manager` | LuCI 管理页面 |
| `luci` | 完整 LuCI，固件尚未包含时选择 |
| `luci-i18n-mesh-manager-zh-cn` | 可选的简体中文翻译 |

选择一种支持 Mesh/SAE 和 802.11k/v/r 的 wpad，例如
`wpad-mesh-openssl` 或 `wpad-mesh-mbedtls`。一个固件只选择一种 wpad，
使用功能完整的变体替换 `wpad-basic-*` 或 `wpad-mini`。

将需要包含在固件中的软件包选为 `[*]`，然后编译：

```sh
make -j$(nproc)
```

编译所得固件包含所选软件包。若使用 SDK 或需要独立安装包，
可将软件包选为 `<M>` 并单独编译：

```sh
make package/feeds/mesh_manager/mesh-manager/compile V=s
make package/feeds/mesh_manager/luci-app-mesh-manager/compile V=s
```

独立安装包须与设备架构和运行固件匹配，使用该固件的包管理器安装，
并补齐依赖。安装完成后刷新 LuCI。

## 使用

### 创建主节点

1. 登录准备作为主节点的路由器，打开 **网络 → Mesh管理**。
2. 选择 **创建管理主节点**，填写 Wi-Fi 名称和密码。
   按网络用途选择路由模式或桥接模式，并保留当前主节点的 LAN 地址。
3. 点击 **创建并启用 Mesh**，检查配置预览并确认应用。
4. 如需无线 AP，在 **回程** 页选择 **802.11s 无线回程** 或
   **有线优先，无线备用**，设置所有节点支持的信道和带宽，确认应用。

主节点应具有正确的系统时间。建议先完成回程配置，再让 AP 加入。

### AP 有线加入

1. 将 AP 的上联口（通常为 WAN 口）连接到主节点的 LAN 口。
2. 登录 AP，打开 **网络 → Mesh管理 → 申请加入**。
3. 将引导 Wi-Fi 名称和密码留空，点击 **加入 Mesh**。
4. 等待主节点发现、配置同步和健康确认完成。

### AP 无线加入

1. 确认主节点已启用 Mesh，并配置了无线回程。
2. 登录 AP，打开 **网络 → Mesh管理 → 申请加入**。
3. 输入主节点的 Wi-Fi 名称和密码，点击 **加入 Mesh**。
   若出现多个同名热点，选择目标主节点的接入点。
4. 等待无线连接、配置同步和健康确认完成。

加入后 AP 的管理地址可能变化，可在主节点 **概览 → 网络拓扑** 中查看。
只有安装了本软件并发起加入的路由器会成为受管 AP；手机、电脑等终端
仍按常规方式连接 Wi-Fi。

### 日常管理与退出

- 在主节点的 **无线** 页统一调整 Wi-Fi 和漫游配置，
  在 **回程** 页调整回程配置；保存后检查预览并确认应用。
- 调整回程模式、信道、带宽或密钥等设置前，先为全部 AP 建立有线上联，
  并按页面的维护提示操作。
- 在 **节点** 页查看和管理 AP，在 **终端**、**变更** 和
  **网络诊断** 页查看连接情况、操作结果和网络检查。
- 临时停用 AP 时，选择 **关闭 Mesh** 并等待原托管配置恢复确认。
  身份绑定保留，可通过 **启用 Mesh** 重新开启。
- 完整退出时，先关闭 AP 的 Mesh 并确认配置恢复，再在主节点撤销
  该 AP 的身份授权。退出后可重新发起加入。
- 关闭主节点的 Mesh 前，先让全部 AP 完成关闭和配置恢复。

恢复后使用设备原有的 LAN 管理地址访问。若页面报告外部配置冲突，
按提示处理后再继续恢复。

802.11k/v/r 的效果取决于终端支持，实际漫游切换由终端决定。

### Guest 与自动射频规划

在管理主节点 **无线 → 高级配置** 中启用 Guest，设置独立密码。
VLAN 和子网可使用 `auto`，也可指定未被占用的 VLAN 和私有 `/24` 子网，
网关地址以 `.1` 结尾。Guest 需要受管的路由模式网关；DHCP 和访问策略由
该网关提供，AP 透明传递带标签的访客流量。

Guest 默认允许上网、隔离同一 AP 上的无线终端，并限制与主 LAN 的访问。
可单独关闭上网或客户端隔离、允许与 LAN 双向互访，或者仅允许 LAN 发起
指定 TCP/UDP 端口的访问。端口例外格式为 `TCP:80,443;UDP:123`。

自动射频规划可选择客户端频段，并分别保留或自动规划信道、功率。
填写设备实际使用地区的国家码；修改国家码时先保留信道和功率并应用，
待驱动更新后再预览自动规划。与无线回程共用的无线电保留全网回程信道。
批准后的信道选择会保持到本次应用完成；应用前仍重新校验法规与硬件能力。
独立 5 GHz 无线电的原生共存机制可在批准的信道块内交换主、副信道；确认时
核对实际信道、带宽、中心频率及功率。共用无线回程的无线电必须保持协调主信道。

功率上限分别下发给每个节点，选择驱动候选值中不超过上限的最大值。
例如，上限为 18 dBm、候选值为 15/20 dBm 时选择 15 dBm；节点最高仅支持
16 dBm 时选择 16 dBm。没有符合上限的候选值会拒绝应用，确认前还会检查
驱动实际报告的功率。6 GHz 使用 WPA3；选择“可用时使用”允许无 6 GHz
的节点使用其他所选频段，选择“每个节点必须支持”则要求全体节点支持。
